Click on a shape to select it, then click on a playable position in the grid to place it there.

Unplayable positions get highlighted with a red inner glow.

If you select a shape that can't be placed anywhere on the grid, it will get outlined in red instead of white.

The blinking outlines in the selector show which part of the given shape gets "grabbed" by the cursor.

The game ends when none of the shape options can be placed.
